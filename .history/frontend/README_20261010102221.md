# 🍢 Cardápio Digital - Espetinho do Chefe 2.0

Um aplicativo web de cardápio digital e sistema de pedidos desenvolvido para facilitar a escolha de produtos e gerenciar o envio das solicitações. O projeto utiliza uma arquitetura moderna dividindo o Front-end (interface do cliente) do Back-end (servidor e base de dados).

## 🚀 Funcionalidades (Visão Prática)

* **Catálogo Dinâmico:** Os produtos e preços são puxados diretamente do banco de dados no servidor, não precisando alterar o HTML para mudar o cardápio.
* **Carrinho Inteligente:** Botões de adição (`+`) e subtração (`-`) que calculam o valor total do pedido em tempo real.
* **Sistema de Identificação:** Janela modal integrada para captar Nome, Telefone e opção logística (Retirada no local ou Entrega com campo dinâmico de endereço).
* **Observações do Pedido:** Campo de texto limpo com limite nativo de 120 caracteres para evitar abusos no banco de dados.
* **Painel Administrativo:** Integração com rota `/admin/login` para gestão do estabelecimento.

## 💻 Tecnologias Utilizadas (Visão Técnica)

* **Front-end:** HTML5, CSS3 e JavaScript (Vanilla, puro sem frameworks para máxima leveza).
* **Hospedagem Front-end:** Vercel (com deploys contínuos e automáticos via repositório).
* **Back-end:** Node.js hospedado na plataforma Render.
* **Controle de Versão:** Git e GitHub.

## 📁 Estrutura Principal dos Arquivos

* `index.html`: Contém toda a estrutura da página, formulários, botões e a janela modal de cadastro.
* `style.css`: Controla o visual do sistema, incluindo o tema escuro, contraste das linhas (usando rgba) e a responsividade para telemóveis.
* `script.js`: O "cérebro" do Front-end. Controla a comunicação com a API, soma matemática dos valores, abertura/fecho de modais e manipulação visual.
